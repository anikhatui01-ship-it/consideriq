# ConsiderIQ — Project Memory

## Product
Working name: ConsiderIQ.
Category: AI Buyer Journey Simulation / AI brand-visibility intelligence.

## Core idea
Simulate how an AI-mediated buyer journey changes as a buyer discovers vendors, adds constraints, compares options, eliminates brands and asks for a recommendation.

## Founder constraints
- solo-founder friendly
- AI coding agents are allowed and encouraged, but code must be reviewed
- fail fast, learn fast
- avoid unnecessary infrastructure
- evidence over assumptions
- beta should stay small

## Technical direction
Next.js + TypeScript + Supabase + Netlify + Cloudflare + Resend + GitHub.

## Data principle
Raw provider responses are immutable evidence. Derived analysis is separate and versioned.

## Product language
Preferred: buyer journey, buyer scenario, consideration set, shortlist, elimination point, evidence, observed response, simulation, model variability.

Avoid: guaranteed ranking, predicts sales, hidden chain of thought, guaranteed recommendation.

## Current milestone
A public beta that a stranger can use without founder intervention.

## Naming history
`BuyerScope` is rejected for now: current web search shows an active BuyerScope real-estate product and historical trademark usage. `BuyerLens` is also already used by multiple products, including an active AI buyer-simulation product. `BrandScope` is also already occupied by multiple current products.

Working brand: `ConsiderIQ`.

Status: preliminary only. Domain, company-name and trademark clearance are still required before public launch.
